# 🏥 Healthcare Performance Dashboard | Power BI

An interactive **Power BI Healthcare Performance Dashboard** developed as a personal portfolio project based on an interview assessment from **Andalusia Group**. The dashboard provides executive-level insights into healthcare performance by integrating data from multiple business domains and presenting key performance indicators (KPIs) through dynamic and interactive visualizations.

---

## 📌 Project Overview

Healthcare organizations generate data from multiple departments such as **Billing, Marketing, and CRM**. The objective of this project was to consolidate these data sources into a single dashboard that enables decision-makers to monitor performance, compare KPIs against targets, and identify trends that support better business decisions.

The project covers the complete Business Intelligence workflow, including:

- Data Cleaning
- Data Modeling
- Dashboard Design
- KPI Development
- Business Analysis

---

## 🎯 Business Objectives

- Monitor overall healthcare performance.
- Compare **Actual**, **Target**, **Baseline**, and **Historical** values.
- Measure business growth and achievement percentages.
- Analyze performance across Business Units and Payment Types.
- Provide executives with an easy-to-use interactive dashboard.

## 📂 Project Workflow

### 1. Data Preparation (Excel)

Before importing the data into Power BI, the dataset was explored using **Microsoft Excel**.

Tasks performed:

- Identified missing (Null) values
- Replaced missing values where appropriate
- Detected and reviewed outliers
- Checked data consistency
- Prepared the dataset for analysis

---

### 2. Dashboard Design (Figma)

Before building the dashboard, the interface was designed in **Figma** to create a clean and user-friendly layout.

The design focused on:

- KPI placement
- Visual hierarchy
- Executive-friendly layout
- User experience (UX)
- Dashboard consistency

---

### 3. Data Modeling

The project uses a **Galaxy Schema**, integrating multiple fact tables with shared dimensions.

The model combines data from:

- Billing
- Marketing
- CRM

Shared dimensions include filters such as:

- Country
- Business Unit
- Payment Type
- Month

The Galaxy Schema improves:

- Scalability
- Performance
- Data organization
- Maintainability

---

### 4. Data Transformation

Power Query was used to:

- Clean data
- Change data types
- Remove unnecessary columns
- Transform data
- Prepare tables for modeling

---

### 5. DAX Measures

Several DAX measures were created, including:

- Actual
- Target
- Baseline
- Historical
- Achievement %
- Growth %
- Revenue KPIs
- Operational KPIs
